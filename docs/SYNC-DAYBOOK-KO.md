# Sync와 Daybook

1. `Settings → Sync`에서 기기 이름과 `webapp-data` 비공개 저장소에 쓸 수 있는 fine-grained PAT를 입력합니다.
2. `Sync now`를 눌러 주소·제목·상태·폴더·태그·메모·하이라이트를 동기화합니다. 저장 본문은 업로드하지 않습니다.
3. Sync가 켜진 다음 `Journal`을 켭니다. 기본값은 활동 수만 보내며 인용문·메모 본문은 보내지 않습니다.
4. Journal을 처음 켤 때 이전 저장 항목은 한 번 소급 기록됩니다.

토큰은 이 기기의 localStorage에만 저장됩니다. 공용 기기에서는 사용하지 마세요.
