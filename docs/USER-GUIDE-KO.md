# 사용 안내

1. 첫 화면의 `+ Add link`에서 URL과 제목을 저장합니다.
2. `Inbox`, `Reading`, `Done` 탭으로 상태를 나눕니다. 원문이나 저장본을 열면 Inbox 항목은 Reading으로 이동하며 Done은 직접 지정합니다.
3. 카드의 `…`에서 폴더 이동, 핀, 링크 복사, 삭제를 사용합니다. 삭제 후 5초 동안 `Undo`할 수 있습니다.
4. Safari에서 저장한 HTML은 `Settings → Import HTML`로 가져옵니다. `Read`에서 본문을 선택한 뒤 다섯 색 중 하나를 누르면 하이라이트가 저장됩니다.
5. 항목 화면의 `Export`로 Obsidian용 Markdown을 받습니다.
